# Credits

Before this project, I earned my spurs on the **Xiaomi Pad 5** — that is where I learned how to create a Linux distribution for a tablet. My thanks therefore go to everyone who helped me to learn all of this (more or less in chronological order):

* **Alexandru Marc Serdeliuc** <https://github.com/serdeliuk> — for making Linux run on Xiaomi Pad 5, which got me into all of this
* **map220v** <https://github.com/map220v> — for important kernel work for the Xiaomi Pad 5
* **maverickjb** <https://github.com/maverickjb> — from whom I learned how to build the kernel and Ubuntu image for Xiaomi Pad 5
* **Pan Ortiz** <https://gitlab.com/panpanpanpan> — for great contributions to the Xiaomi Pad 5 kernel
* **rodriguezst** <https://github.com/rodriguezst> — for the dual-boot idea that I adapted to the OnePlus Pad 3
* **Timofey** <https://github.com/timoxa0> — for his rEFInd setup files for the Xiaomi Pad 5 which I used on the OnePlus Pad 3 as well
* **Kumar-Jy** <https://github.com/Kumar-Jy> — for his packaging idea that I adapted to the OnePlus Pad 3
* **Cheng Fangming** <https://github.com/CFM880> — from whom I adopted the autofocus camera code
* **Vishram1123** for his great on-screen-keyboard, see https://extensions.gnome.org/extension/5949/gjs-osk/
* **Laurie Lin** for TWRP, see https://xdaforums.com/t/recovery-unofficial-android-16-twrp-3-7-1-for-oneplus-pad-2-pro-pad-3.4781650/
* **Marcos Horno Garcia** — a very special thanks for beta testing!
* **OnePlus** for this powerful tablet and for open sourcing a good bunch of the Android drivers for it
* Last but not least: the **Linux kernel, Ubuntu, Gnome** and **Mu-Silicium** teams and everybody else who contributed to the linux project!

The linux kernel drivers and device tree for this pad were written with the help of AI, mainly "Claude Opus 4.8" by **Anthropic**. Some minor corections with "GLM-5.3-Flash" by **z.ai** and recent corrections and features with "Deepseek Flash 4.1" by **deepseek.com**.

## Licenses

Everything here is open source — the kernel and drivers are GPL-2.0, plus ISC/BSD/MIT parts — except the OnePlus/Qualcomm firmware blobs and DSP/NPU runtime libraries, which are proprietary.
