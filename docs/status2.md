# Status 2 — Ubuntu on OnePlus Pad 3 (erhai)

## Works

- display 3392×2400, 2× scaling
- refresh rates 30 / 48 / 50 / 60 / 90 / 120 Hz
- brightness control
- power button: screen fully off / on (3-4 s)
- GPU acceleration
- external monitor over USB-C (hub, HDMI)
- hardware video decoding in browsers
- touchscreen (multi-touch)
- internal speakers (6 amps)
- magnetic keyboard + trackpad
- USB / Bluetooth keyboard & mouse
- fold keyboard cover: screen + touchscreen off
- OnePlus Pencil 2 (Bluetooth)
- pen charging dock (CPS8601, stops at 100 %)
- dock: one-finger icon scrolling
- desktop: one-finger long-press menu
- Files: empty-space menu, select boxes, one-finger drag, rename with OSK
- Terminal: finger scrolling, long-press copy, Paste button
- on-screen keyboard (pogo-gated, Shift/Ctrl/Alt)
- 3-finger workspace swipe
- auto-rotation
- automatic brightness
- Wi-Fi
- Bluetooth (devices, audio)
- USB-C: hubs, storage, displays, charging
- charging while hosting USB devices
- SuperVOOC fast charging (SC8547A)
- PPS/PD fast charging (PMIH0108)
- bypass charging
- battery percentage, temperature, current
- configurable charge limit
- sound over USB-C monitors
- rear + front camera
- ErhaiCam (autofocus, photos, video)
- dual-boot with Android
- four performance profiles
- NPU: local LLMs via `npu-llm` (use a cooler!)
- OTA kernel/app updates
- MIDI

## Does not work

- real sleep / suspend
- 144 Hz (removed on purpose)
- internal microphones
- video recording with sound
- USB-C headphones (untested)
